# 当代左派评论与观点语料库

## 📖 项目介绍

本项目旨在系统收录**当代左派评论与观点**，汇编为 **209 条高质量的政治理论训练语料**。语料横跨马克思主义经典理论、革命实践、计划经济理论与现代批判理论等谱系，呈现当代左翼思潮围绕阶级、劳动、组织与历史动力所展开的分析与论辩。全部数据均经过主题分类与质量校验，可直接用于 AI 问答模型训练、学术研究分析或政治理论教育教学。

## 🧠 数据特点

- **总条目数**：209 条高质量问答对
- **数据格式**：标准 JSONL 和 JSON 格式
- **覆盖领域**：马克思主义理论、革命实践、经济制度、哲学思考等
- **分类规范**：按主题自动分类，便于检索和使用

## 📚 数据组织结构

1. **马克思主义理论基础**（37 条）— 辩证唯物主义、历史唯物主义、社会主义经济理论
2. **印度革命理论**（14 条）— 社会性质分析、革命战略、阶级分析
3. **秘鲁革命经验**（19 条）— 战略目标、人民战争实践、党的建设
4. **计划经济理论**（19 条）— 基本原理、理论发展、实践应用
5. **组织理论**（15 条）— 党的建设和组织原则
6. **反对劳动理论**（15 条）— 资本主义异化分析、劳动批判
7. **现代批判理论**（45 条）— libcom.org 理论文献、霍洛韦文选、联邦党人文集
8. **政治制度理论**（25 条）— 联邦制、市场经济机制分析

## 📥 使用方法

### 方式一：直接使用数据

```bash
# 查看原始数据
cat data/training_corpus.jsonl

# 查看分类数据（按主题）
ls sources/libcom/
ls sources/marxist_theory/
```

### 方式二：运行处理脚本

```bash
# 运行数据验证（确保数据完整性）
python scripts/final_validate.py

# 运行自动分类处理（如果需要重新分类）
python scripts/auto_classify_final.py
```

### 方式三：添加新内容

原始数据结构示例：

```json
{"messages": [{"role": "system", "content": "你是一个学习政治理论和革命思想的智能助手。你基于提供的文档回答问题。"}, {"role": "user", "content": "如何理解印度是半殖民地半封建社会？"}, {"role": "assistant", "content": "当今印度社会是新殖民主义间接统治……"}], "source": "印度革命的战略与策略", "category": "社会性质"}
```

创建 txt 文件后运行 `python scripts/auto_classify_final.py` 即可自动处理。

## 🛠️ 项目工具说明

| 脚本 | 功能 |
| :--- | :--- |
| `scripts/auto_classify_final.py` | 自动识别文件来源和主题，按分类结构存储，支持增量处理 |
| `scripts/validate_training_data.py` | 验证 JSON 结构、字段完整性、数据质量 |
| `scripts/final_validate.py` | 综合验证、分类统计、输出详细报告 |
